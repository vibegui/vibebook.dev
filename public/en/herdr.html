vibebook herdr runs on your computer and links each room to its project. In the room you click ✻ Turn on Claude, and it opens a Claude Code in the project's folder, in a herdr tab, already listening to the room.

Run it once, in a terminal, and leave it open vibebook herdr

Before: vibebook connected to your Claude Code (it's one sentence) and herdr open.

What happens when you click

  1. The button already shows the folder. Next to “✻ Turn on Claude” you see where it will open; hover for the full path and why.
  2. The app tells vibebook the room is on. That's all that leaves the browser. The folder path never reaches the server; only your computer knows your folders.
  3. Within 15 seconds vibebook herdr opens a tab named after the room and runs claude /vibebook:listen in the folder, resuming that room's last conversation.
  4. Claude starts listening. The button turns into “✻ listening”, and the ↗ next to it jumps to its tab in the terminal.
  5. Turning it off closes the tab. The conversation is kept, and turning it on again picks up where it stopped.

How it picks the folder

Without asking. The first rule that applies wins:

  1. The folder it used before for that room (kept in ~/.vibebook/herdr.json).
  2. The folder linked to the room: the one with a .vibebook file holding its id, in ~/Projects up to two levels down (~/Projects/clients/booking counts). That's what /vibebook:setup creates, and the room's name doesn't matter there.
  3. ~/Projects/ + the room's name without accents, lowercase, with hyphens: “Summer Launch 2027” becomes summer-launch-2027. If the folder exists it uses it; if not, it creates it.

It writes the .vibebook into the chosen folder (kept out of git via .git/info/exclude), so next time it's the same one.

go
  • One tab per room, in your rail's order. Drag rooms in the app and the tabs follow. Your other tabs come after, untouched.
  • Already had a Claude open in that folder? It adopts that one instead of opening another. If it's busy, it waits until it's free to ask it to listen.
  • New folder: Claude Code asks whether you trust it. That answer is yours, and you give it in herdr.
  • Moving a room to another folder: turn it off, delete the room's line in ~/.vibebook/herdr.json and run /vibebook:setup in the right folder.

Safe by default

  • The local server only listens on 127.0.0.1:47321 and only answers the vibebook page you're signed into, at the exact address (DNS rebinding is refused).
  • vibebook only knows “on” or “off”. Folder paths, machine names and conversations stay on your computer.
  • The Claude it opens is yours, with your permissions. What other people write in the room arrives as information, and it asks you before acting.
