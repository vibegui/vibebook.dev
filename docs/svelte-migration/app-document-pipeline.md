# Document-bound app build and vanilla integration

`bun run build:app-document` uses the existing guarded browser builder to emit a classic IIFE bootstrap as `shared/generated/appDocumentBootstrap.ts`, then an ES-module host as `public/app-document-host.<sha256-prefix>.js`. The build validates one nonce slot, no closing script token, one lexical IIFE wrapper and exactly one vanilla host import. Only obsolete files matching the exact host asset pattern are removed. Both the server and browser consume the same generated bootstrap string. API types/dev/build and deployment run this step before consumers.

Vanilla lazily imports that content-addressed host. Panel and inline HTML apps get a fresh iframe per grant; file apps use the authenticated same-URL nonce POST, remote HTML uses bootstrap-bearing srcdoc. Raw SDK and legacy messages are proposals delivered only through the host's document challenge. Private responses go exclusively through its port/payload-reference API. Consent is re-attested before a write, with room/account/thread/Book-connection ownership checked after asynchronous work. Removed frames release listeners/ports, and a refreshed Book connection cannot reuse an old frame grant.

Validation after the BOM correction: guarded generation passed; the eight injection cases, two pipeline cases and five actual mounted Hono file-navigation cases passed together (15 tests / 131 assertions, 2.24 seconds). The generated host and vanilla import were regenerated from that source; scoped strict TypeScript passed. The Hono fixtures exercise authorization, exact policy/URL semantics, bounded nonce forms, invalid MIME/range/query inputs and no SQL/R2 writes. Compact vanilla inline scripts previously parsed with Node, but actual vanilla UI/Worker/file-POST/SDK behavior remains unrun here.

`bun run test:app-document:browser` is a separate real Chromium fixture: opaque srcdoc, native MessageEvent payload/source/origin/isTrusted, and same-frame/WindowProxy replacement denial. Its GitHub job retains safe synthetic JSON. No browser execution is claimed by this source checkpoint. The additional adversarial SDK/held-output/consent/reopen matrix is a separate work item. No claim of Safari, BFCache, production provider or complete application security acceptance follows from the minimal fixture.

The new public host is approximately 304 KB raw at this checkpoint because HTML injection includes the actual parser/schema dependencies. It is loaded only when an app opens; this is a size observation, not a measured runtime performance claim.

Vanilla follow-up: per-owner abort signals now settle both active and queued consent questions on revocation/disposal. Cleanup only removes the exact question's controls; detached controls cannot advance a different question. Expired frames remain connected but hidden for public denial responses, with a translated parent notice and a Reopen action creating a fresh iframe/grant. Model-context dispatch rechecks current ownership after attestation. Two tests execute the extracted actual vanilla consent implementation with real DOM controls (2 pass / 9 assertions); scoped strict TypeScript passed. These are queue/ownership tests, not browser transport/security acceptance.

Development now owns a serial generator watcher for bootstrap/host/shared injection sources. The supervisor starts it after Worker/Vite readiness, waits for its explicit successful initial-generation signal before declaration watch, and reaps it with the other children. Directory watches survive atomic editor replacements, ignore generated output, coalesce edits during generation, and remain available after a reported compile failure for a later corrected edit. Shutdown aborts later artifact writes and bounds an uninterruptible build's process lifetime. Initial failures never report ready. These source changes were checked with 10 focused queue/supervisor/real-fs-watch tests (60 assertions) and the scoped strict config including the supervisor. Actual dev:app regeneration/reload and process-tree cleanup remain a separate HMR runtime gate.
