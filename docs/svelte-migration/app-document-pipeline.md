# Document-bound app build and vanilla integration

`bun run build:app-document` uses the existing guarded browser builder to emit a classic IIFE bootstrap as `shared/generated/appDocumentBootstrap.ts`, then an ES-module host as `public/app-document-host.<sha256-prefix>.js`. The build validates one nonce slot, no closing script token, one lexical IIFE wrapper and exactly one vanilla host import. Only obsolete files matching the exact host asset pattern are removed. Both the server and browser consume the same generated bootstrap string. API types/dev/build and deployment run this step before consumers.

Vanilla lazily imports that content-addressed host. Panel and inline HTML apps get a fresh iframe per grant; file apps use the authenticated same-URL nonce POST, remote HTML uses bootstrap-bearing srcdoc. Raw SDK and legacy messages are proposals delivered only through the host's document challenge. Private responses go exclusively through its port/payload-reference API. Consent is re-attested before a write, with room/account/thread/Book-connection ownership checked after asynchronous work. Removed frames release listeners/ports, and a refreshed Book connection cannot reuse an old frame grant.

Validation at this checkpoint: guarded generation passed; two pipeline tests plus seven initial injection cases passed (9 tests / 39 assertions); scoped strict TypeScript passed. The parent subsequently corrected BOM tokenization and expanded injection fixtures: those changes need regeneration and a new receipt. Compact vanilla inline scripts parse with Node, but actual vanilla UI/Worker/file-POST/SDK behavior is unrun here.

`bun run test:app-document:browser` is a separate real Chromium fixture: opaque srcdoc, native MessageEvent payload/source/origin/isTrusted, and same-frame/WindowProxy replacement denial. Its GitHub job retains safe synthetic JSON. No browser execution is claimed by this source checkpoint. The additional adversarial SDK/held-output/consent/reopen matrix is a separate work item. No claim of Safari, BFCache, production provider or complete application security acceptance follows from the minimal fixture.

The new public host is approximately 304 KB raw at this checkpoint because HTML injection includes the actual parser/schema dependencies. It is loaded only when an app opens; this is a size observation, not a measured runtime performance claim.
