# Production RoomLayout source checkpoint

This source adopts the mechanism proven by the isolated geometry checkpoint95b205b; it is not a production runtime receipt. Every production formatter, pure/DOM/type/style/build/browser gate remains UNRUN until the shared-machine owner allocates a slot. Existing prototype branches and failed/passing artifacts remain preserved.

`features/room-layout/types.ts` defines the public contract. `createRoomLayout` is a per-room/account/connection presentation owner; the data owner supplies a fixed `scopeKey`, `current` guard and real `onDocumentClosed` callback (document mode→preview). It owns no room transport, canonical data, provider or persistent UI variant. The optional Viewer gate defers geometry intents behind an already requested Viewer Back. RoomScope's application adapter must still consume FileViewer pop/Forward restoration first, then `layout.consumePop`; navigation deferral likewise checks Viewer first. `beforeNavigation` clears only an owned sheet marker without asynchronous Back. `takeSheetEntry()` returns true only when the caller must replace its next thread-route entry. User close waits for actual Back and retains unconfirmed/deferred state on timeout, with explicit retry rather than treating a missed event as completed navigation.

`RoomLayout` renders each caller snippet once: sidebar, header, peek, attention, chat, composer, desktop document toolbar, document content and Board. The Board is one stable direct CSS-grid child; its full-chat/document-pane classes change without Portal, DOM relocation or remount. Only controller identity keys the containing owner. Header, peek and attention use natural grid rows; attention remains outside the message scroller. The actual chat scroll element is supplied through `onChatSurface`; `onCells` exposes exact owner cells with cleanup. RootApp must allocate a definite height to the room cell.

Layout owns sidebar/document grab buttons, the peek drag action, scrim, desktop native range input and safe-area wrappers. Sidebar's old optional sheet-handle adapter must be hidden by the direct RoomScene. Width uses actual room-container width, expanded sidebar272px or rail68px,260px document minimum and a320px preferred chat reserve; below physically possible minimums the chat grid uses minmax(0,1fr), matching the baseline's nonoverflowing behavior. The mobile breakpoint remains the existing viewport900px. Saved `vb.docW` persists user intent; viewport clamping does not overwrite the stored width.

All first-party presentation is declared in the single Tailwind entry, including the paused animations. The typed adapter seeks only genuine CSSAnimations with exact names/KeyframeEffect targets. Pending drags observe owned window events before six-pixel capture, preserving child-button taps while fixing the measured first-step jump outside a small handle. Quarter-height release uses actual captured height and last pointer on cancel. Release interpolation uses the existing300ms curve, skipped for reduced motion. Observers, pending animation discovery, pointers, timers and callbacks are cancelled on exact-owner teardown. No style/CSSOM writes, Element.animate, authored JS keyframes or legacy head/peek CSS variables are introduced.

Two formerly inconsistent legacy flag edges are normalized explicitly: choosing Board as a document pane ends full-chat Board mode, and opening a mobile document pane leaves full-chat Board mode so its peek/tab controls stay reachable. Desktop full-chat Board can coexist with a reopened right document pane. These placement choices need source review and actual integrated parity validation.

Pending adoption gates include real Viewer/sheet Back/Forward ordering, safe-area/visualViewport keyboard behavior, rapid pending gestures, width/rail changes, mode/permission/account transitions and stable Board DOM/selection. Safari/hardware touch/assistive technology are not established by the earlier Chromium prototype proof. The legacy shell and stylesheet remain until the complete RoomScope/RoomShell/RootApp integration is validated and retired by their owners.
