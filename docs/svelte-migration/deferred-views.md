# Demand-loaded native views

The measured current native entry cohort requested 452,333 gzip bytes of HTML/JS/CSS. This source change removes static UI imports for inactive room panels (Files, Apps, Decisions, Reminders, Agents, Board and File Viewer) and dormant application views (Home, Archived, account settings and Inbox). Chat, Composer, the initial document, data services, draft bags, room ownership and the device-lock barrier stay eager. Exact byte savings require a rebuilt request trace; no savings or budget pass is claimed from source inspection.

`createDeferredModule<T>` requests only an actual visible pane, route or modal intent. One owner shares an in-flight Promise and retains the exact settled component across store updates. A 20-second owned deadline or rejection presents an accessible explicit retry; passive updates do not retry failures. Native imports cannot be cancelled, so timeout/disposal fences ignore late completions and release the departed ownership predicate. Scene destruction still disposes services and views normally. The cache stores public module code, never account/room data.

Board is still mounted once after first visible use and retained across placements. Existing CSS-hidden panels remain mounted after their first load; Agents keeps its existing active-pane mount lifetime. Module readiness does not start new service owners or clear drafts. Home/Archived retain their previous route mount lifetimes. Home is requested immediately on an actual Home route, and is not prefetched behind a room benchmark. Initial Home and each first pane load must be included in real timing/byte measurements.

While a modal module loads, its existing owner remains authoritative and a dismissible native loading/error dialog preserves keyboard/Back handling. Closing an old account/Inbox placeholder is bound to its immutable owner token. A late module load cannot reopen a closed modal. File Viewer keeps its pending-close warning even if its module failed. Device Lock remains eager so a locked device never exposes underlying content while its blocking UI downloads.

Source-authored tests cover shared pending-module identity, stable component identity, departure/disposal, deadline/retry and ignored late results. DOM fixtures cover retained actual local draft nodes across hide/show/store changes and late resolution after target reuse. They are not browser/network proof. Formatting, strict Svelte/tooling, DOM execution, actual modal focus/history, source HMR, production chunk accounting and the real Worker/Studio cohorts remain pending for this checkpoint. No local compiler/build/browser process was run.
