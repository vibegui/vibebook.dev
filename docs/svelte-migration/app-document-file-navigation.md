# Bound-document file navigation POST

This server-only slice adds `POST /api/books/:id/files/:fid` for a fresh bound app document. Root-owned `shared/appDocument.ts` supplies the strict64-lowercase-hex nonce schema and first-script bootstrap. The nonce is request-body presentation data, never an account/file authorization credential. Existing identity middleware and the exact existing `isMember` query remain authoritative.

The route requires the exact request Origin (compatible with the existing trusted Vite proxy Origin translation), rejects cross-site metadata, Range and all URL query modes, and accepts only a256-byte maximum URLencoded form containing exactly one nonce. Multipart/File, duplicate and unknown fields are refused before storage reads. It reads the same authorized R2 object and accepts only stored `text/html`; no HTML body, file metadata or target URL comes from the form.

The response preserves the existing file MIME, disposition, opaque sandbox CSP, no-network rule, referrer policy and same file URL/base. Bootstrap insertion leaves the source doctype and relative resources intact. Cache policy changes to private/no-store with no ETag, Last-Modified or Content-Length. This handler performs no SQL, R2, Book or personal-channel writes. The global one-time known-user/signup/schema behavior is unchanged from every existing authenticated GET. An exact route/method predicate excludes only this successful navigation POST from the generic mutation-triggered personal refresh; uploads and all other API mutations retain their existing poke.

The original file GET handler—including ranges, Escape injection and download behavior—is unchanged. Browser same-frame document authority and port binding are owned by the separate root bootstrap/host slice. Actual form joint-history/Back, CSP/base resource behavior and live Worker authorization remain future integrated browser gates.

Five source-authored Hono fixtures cover valid bootstrap order/doctype/CSP/base/no-write, missing identity and foreign/missing Origin, membership removal, malformed/duplicate/oversized/File forms, nonHTML/missing files, Range/query refusal and exact poke exemption. These are actual route/SQL-read/R2-read port fixtures, not a real D1/R2/DO/Worker receipt. All formatter/tests/types/browser/build UNRUN at this checkpoint; shared bootstrap contract integration is pending root's source.
