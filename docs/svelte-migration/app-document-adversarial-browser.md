# Document-bound channel adversarial browser matrix

`auditAppDocumentAdversarial({page,hostModuleURL,output})` extends the separate minimal native-event browser runner. It uses the actual generated host module, opaque sandboxed `srcdoc`, native MessagePorts and an independent second HTTP origin serving the replacement document. Every navigation uses the child realm's real `location.href`; `srcdoc` is never incorrectly bypassed by assigning `iframe.src`. After the replacement responds, the fixture verifies the original iframe element and WindowProxy are still identical, the child URL equals the second-origin endpoint, and its origin is opaque.

Source cases include real installed stock MCP Apps SDK1.7.4 initialization/read positive, legacy no-initialize raw RPC positive, replacement direct tools/call without initialize denied, a held private output after navigation rejected, a held consent followed by navigation reattested without incrementing a simulated write counter, and explicit fresh-iframe reopen succeeding. A positive same-document consent control increments that synthetic counter exactly once; these counters are not canonical server writes.

Actual subframe history Back is attempted and a restored document must never regain the old grant. Its actual `pageshow.persisted` flag is recorded. A separate explicitly labeled synthetic persisted pagehide/pageshow control covers permanent revocation in the same realm. If the real browser does not admit BFCache, this is not reported as actual BFCache acceptance; the evidence retains that gap rather than disguising the synthetic event as real history behavior.

Artifacts contain only synthetic counts/booleans and safe fixed failure names. No provider keys, auth headers, real room data, HAR or production writes are involved. This helper is a browser unit-integration matrix, **not** the real Worker file-POST/provider/SDK authority probe. That integrated probe remains independently required. All new cases are source-only/unformatted/untested at the initial checkpoint; no browser acceptance is claimed.
