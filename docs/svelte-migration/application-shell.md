# Direct application shell source

AppShell composes the existing Home/Archived/AppNavigation/AccountSettings/device lock and Inbox components through typed props. BrowserApplicationServices is supplied once; AppShell starts it once and releases it on destruction. It creates no Personal/PWA/Agents/Room data owners and imports neither legacy host nor main/mount registry. Room content is a required typed snippet receiving `{ services, openInbox }`; the parent RoomShell implementation remains required before bootstrap changes. No placeholder room or disabled feature is shipped.

AccountPanel now takes real notification/agent snippets. AccountSettings supplies NotificationBell and AccountAgentSettings directly using existing service owners. Its old host compatibility entry only supplies the existing PWA/Agents/Account instances; two DOM mount callbacks and the nested AgentSettings mount function are removed. Immutable Account Snapshot controls and draft preservation remain intact. Existing Account security DOM cases now mount AccountPanel directly with inert snippet fixtures.

The global Inbox controller reads canonical Personal waits and captures account/revision/opening identity. Before-flush old controls cannot resolve or navigate a replacement account/opening. Late resolve completion cannot refresh another owner; known global401 invokes the existing terminal services boundary. Explicit resolves use the existing typed HTTP command, without automatic retries. Theme, language and data-nav browser effects have explicit cleanup; no stylesheet, inline presentation injection, auth business rule or transport policy is added. AppNavigation's update prompt calls the supplied reload action. Its creator now captures immutable NewRoomBinding via Snapshot so outgoing connected inputs/forms cannot change a newer draft or submit it.

Source cases cover direct shell routes/required snippet, singleton cleanup, actual profile confirmation plus direct PWA/agent snippets, before-flush creator replacement and global Inbox identity changes. Four pure Inbox cases cover canonical target loss, late result disposal, terminal401 and a bounded ignored-abort deadline. Browser/provider/PWA/real RoomShell/layout parity remains a later integration gate.

Prerequisite: original service commits f547fe4 +814f5e0 (+delete-only cache820011f). Local copied prerequisite refs must not be replayed alongside their originals. Bootstrap is unchanged. All formatter, tests, type/style checks, build and browser gates are UNRUN under root resource hold.
