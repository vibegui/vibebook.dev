# Native rich text: F18 reading surface

The real Message mount renders human text, Markdown, reminder bodies, issue headings and folded notice bodies through `RichContent`. `LegacyChatIntegrations.richText` has been removed. Typed text, mention, link and allowlisted element nodes render through Svelte; no HTML string rendering or browser HTML parser is used in this path.

Marked is pinned to 12.0.2, matching the previous global grammar. Its GFM lexer supplies headings, emphasis, strike, code, lists/tasks, tables, references, links and hard/soft breaks. Source-wide emoji replacement shares the existing dictionary with the composer. Human messages retain literal text and HTTP(S) linkification. Mentions retain canonical member aliases and `@ai`/`@vibe` recognition. GitHub/file chips and message/thread/document links use typed scoped callbacks; uploaded-file links retain exact immutable IDs and known version numbers, with a typed partial-metadata viewer fallback.

`markdownTree.ts` is the sole parse5 adapter. parse5 8.1.1 is an exact runtime pin: its exported Parser/token-event helpers are marked internal upstream, so upgrades must pass the split-inline-tag, cross-block details, namespace, table and text-flush regressions. Raw fragments and semantic Markdown tokens enter one inert parser stack, preserving harmless HTML split across lexer tokens without serialization, DOMParser, network fetches or HTML insertion. Its supplied flushCurrentCharacterToken API completes raw character tokens before semantic events. entities 7.0.1 is a direct runtime dependency for URL/text entity decoding.

Raw HTML retains the prior harmless HTML, SVG and MathML allowlists, including details/summary and tables. Forbidden execution/control/embed/image/style elements and attributes remain excluded. User classes, IDs, first-party data/action hooks, event handlers, inline styles and focus/control attributes cannot cross the projection. IDs and their local references become component-private IDs; existing local IDs take priority over app-navigation hashes. URL entity decoding and URL parsing enforce the baseline safe explicit protocols and relative URLs. SVG/Math resource references require private local targets or known same-room uploaded images. Presentation values reject CSS escapes/comments and disguised external resources.

A component-owned one-entry session retains syntax by text/mode and projection by relevant member/name/me/file metadata. Fresh receipt/presence snapshots reuse the projection; unchanged reducer array/map references also avoid fingerprint scans. Disposal releases source, syntax, projection and context references. No global text or cross-account cache exists.

Resource limits produce one escaped, whitespace-preserving literal node rather than partially rendering a hostile graph: 64 KiB source, 48 token/tree levels, 4,096 emitted parser elements, 2,048 projected tree nodes and 128 SVG nodes. SVG numeric lists, magnitudes and turbulence octaves are bounded. Canonical source remains available unchanged for copy/edit. Limits are a deliberate rendering safety boundary, not a mutation of stored messages.

The former `interactiveBody` fragment is retired by [native interactive message bodies](native-chat-interactive.md). `threadCards`, F49 embed protocol, composer/docs Markdown and the remaining host shell remain explicit pending work. Their vendor globals stay until those owners migrate. This retires one actual HTML integration; it does not complete all F18 composer behavior, F15–F23, or M6.

Focused pure tests cover syntax, split raw tags, namespaces, URL schemes and obfuscation, action-hook stripping, private IDs, canonical file versions, mentions/emoji and resource fallback. DOM interaction fixtures are source-only until root runs the integrated DOM gate. Type, style, build, browser, mobile and artifact gates remain root-owned.
