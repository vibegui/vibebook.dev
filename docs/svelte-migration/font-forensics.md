# Rejected Studio font diagnostic

This research-only workflow never imports application code, changes font CSS, builds assets, or activates a derivative. Trigger it with `run-font-forensics` on a pull request (remove/re-add to rerun), or dispatch `Diagnostic Studio font forensics`. A successful workflow means diagnostic controls completed, **not** font acceptance or a passed performance budget.

`coverage.json` establishes that all seven historical failed raster rows used the same string: all 37 distinct codepoints exist in both cmaps. Additional Euro, curly single/double quote, NBSP, composed Portuguese and decomposed combining-mark controls also have full coverage. Cmap coverage does not substitute for actual browser font evidence.

Private Python forensics found exact retained outlines/advances/side bearings at weight400/opsz14 and900/14 across1011 retained codepoints. The original full regular/italic Inter fonts roundtrip through fontTools4.68.0/Brotli1.2.1 byte-for-byte. Those facts do not explain or waive the seven earlier Chromium158 raster failures. Historical natural canvas ignored explicit optical-size settings, so repeated optical rows were not independent optical raster comparisons.

The checked-in **rejected** research artifact is the historical202292-byte candidate, with fixed digest/license/provenance under `scripts/fixtures/font-forensics`. The roundtrip artifact is the actual generated file, whose bytes equal the original352240-byte Inter. Original production assets remain unchanged. Neither artifact has an application import or stylesheet reference.

The browser harness uses one context with original A/B aliases, actual roundtrip and rejected subset. It asserts exact A/A and roundtrip pixel equality, actual Inter custom-font CDP identity, and a deliberately excluded-font positive fallback control. It records weight400/900 natural32px canvas pixel-change counts, channel deltas and bounds for individual characters and shaped clusters, saving at most16 mismatch pairs. Explicit DOM optical14/32 screenshots are independently pixel-compared in the browser; canvas is honestly labeled optical-default. All text is synthetic and screenshots contain no account/auth/production data. The full original is used for these controls; no candidate is eligible for activation.

A discrepancy-localized result identifies where the browser differs; it does not by itself prove the font table cause. A nonreproduction result is browser/version-specific negative evidence. An A/A/fallback/identity failure is inconclusive and fails the job. Source-only authoring: formatter, typecheck, workflow and browser execution initially UNRUN. Future subsets require exact retained GIDs/layout/metrics/variation verification, original-face complementary Unicode fallback, independent raster acceptance, integratedRoot Studio proof and unchanged M4/M7 budgets.

It verifies original/rejected digests, retained raw blocks, original GIDs/table identity, checksum and exact output digest. The executed private source passed these assertions with actual `/proc/self/status` VmHWM86700KiB. The path-adapted checked-in recipe has not been rerun; remote browser evidence remains pending.

All292 canvas A/A/roundtrip comparisons and eight explicit-optical DOM controls were zero; all advances matched. Missing U+10FFFF separately exposed a330-pixel missing-glyph difference. The same browser recipe retains old `Rejected` failures as a diagnostic reference, asserts exact A/A controls, reports `Retained` independently, and requires actual downloaded bytes/digests for all faces. Neither a successful diagnostic job nor zero observed differences activates fonts, waives budgets, establishes universal shaping, or replaces required italic/mono/all-role/all-weight/integrated EN/PT light/dark1440/390 fidelity proofs. Original full-face production CSS/assets stay untouched. This same-coverage causal candidate alone cannot meet the total font budget.
